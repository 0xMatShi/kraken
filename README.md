# MMDNA - Polymarket Market Making Bot

> Автоматический маркет-мейкер для бинарных рынков предсказаний Polymarket с алгоритмом хеджирования позиций

[![Rust](https://img.shields.io/badge/rust-1.94.0--nightly+-orange.svg)](https://www.rust-lang.org/)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

## Описание

MMDNA (Market Making DeltaNeutral Arbitrage) — это высокопроизводительный торговый бот на Rust, предназначенный для автоматической торговли на платформе Polymarket. Бот реализует стратегию нейтрального хеджирования, комбинируя пассивные maker-ордера с активным управлением позициями для поддержания сбалансированного портфеля и получения прибыли на спреде.

### Ключевые возможности

- **Автоматическое сканирование рынков** - поиск торговых возможностей по заданным критериям
- **Dual-sided market making** - одновременное размещение ордеров на покупку и продажу
- **Динамическое хеджирование** - автоматическое выравнивание позиций при перекосе портфеля
- **Защита от убытков** - система экстренного закрытия позиций
- **Real-time WebSocket** - мгновенная реакция на изменения рынка
- **Детальная отчетность** - логирование всех сделок и статистики

## Как это работает

### Торговая стратегия

```
┌─────────────────────────────────────────────────────────────┐
│  1. Сканер ищет подходящие рынки                            │
│     - BTC-updown-15m events                                  │
│     - Временное окно: 0-15 минут до истечения               │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│  2. Подписка на WebSocket стримы                            │
│     - Market Data: обновления ордербука                     │
│     - User Events: подтверждения сделок                     │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│  3. Торговый цикл (на каждое обновление цен)               │
│                                                              │
│  IF |перекос позиции| >= 3.0:                               │
│    → Хеджирование (taker-ордер на противоположную сторону)  │
│                                                              │
│  ELSE IF цена входа + противоположный ask > 1.05:           │
│    → Экстренное закрытие позиции                            │
│                                                              │
│  ELSE:                                                       │
│    → Размещение парных maker-ордеров (TTL 5 секунд)        │
│    → Цена = лучший bid + 0.01 (при ликвидности > 100)      │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│  4. Обновление портфеля при исполнении ордеров             │
│     - Отслеживание shares (UP/DOWN отдельно)                │
│     - Расчет средней цены входа                             │
│     - Подсчет общих затрат                                  │
└─────────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────────┐
│  5. Финализация при окончании рынка                         │
│     - Расчет PnL                                             │
│     - Сохранение отчетов (JSON + TXT)                       │
│     - Обновление глобальной статистики                      │
└─────────────────────────────────────────────────────────────┘
```

### Типы ордеров

#### Maker Orders (пассивные)
- Лимитные ордера с ценой чуть выше лучшего bid
- Размещаются парами на обе стороны (UP/DOWN)
- Автоматическая отмена через 5 секунд
- Пропускаются если стоимость пары >= 0.99 (нет маржи для прибыли)

#### Taker Orders (активные)
- Рыночные ордера с исполнением FAK (Fill and Kill)
- Используются для хеджирования при перекосе позиции
- Экстренное закрытие при угрозе убытков

### Управление рисками

- **Hedge Size**: перекос более 3.0 шеров → немедленное хеджирование
- **Emergency Cover**: если `cost_basis + opposite_ask > 1.05` → закрытие позиции
- **Max Balance**: ограничение на максимальный размер позиции
- **Order TTL**: maker-ордера живут только 5 секунд

## Установка

### 1. Установка Rust

Если Rust еще не установлен:

```bash
# Установка rustup
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Установка nightly toolchain
rustup install nightly
rustup default nightly
```

Проверьте версию:
```bash
rustc --version
# Должно быть: rustc 1.94.0-nightly или выше
```

### 2. Клонирование репозитория

```bash
git clone <repository-url>
cd mmdnca-main
```

### 3. Настройка окружения

Создайте файл `.env` в корне проекта:

```env
# Polymarket Credentials
POLYMARKET_PRIVATE_KEY=your_wallet_private_key_here
FUNDER_ADDRESS=0xYourWalletAddress
POLYMARKET_API_KEY=your-uuid-api-key
POLYMARKET_API_SECRET=your_api_secret
POLYMARKET_API_PASSPHRASE=your_passphrase

# WebSocket URLs
CLOB_WS_MARKET=wss://ws-subscriptions-clob.polymarket.com
CLOB_WS_USER=wss://ws-subscriptions-clob.polymarket.com
```

**Как получить API credentials:**
1. Зарегистрируйтесь на [Polymarket](https://polymarket.com)
2. Перейдите в настройки API
3. Создайте новый API ключ
4. Сохраните все credentials в `.env`

### 4. Сборка проекта

```bash
# Проверка компиляции (быстро)
cargo check

# Production сборка
cargo build --release
```

## Использование

### Запуск бота

```bash
# Development mode
cargo run

# Production mode (оптимизированный)
cargo run --release
```

### Интерактивное меню

После запуска вы увидите меню:

```
1) Scan for a market and trade
2) Exit
Enter your choice:
```

**Выберите опцию 1** для начала сканирования и торговли.

Бот автоматически:
1. Найдет подходящий рынок (btc-updown-15m в окне 0-15 минут)
2. Подключится к WebSocket стримам
3. Начнет размещать ордера и хеджировать позиции
4. Будет работать до истечения времени рынка

### Просмотр результатов

Все результаты сохраняются в папке `results/`:

```bash
# Отчет по конкретному event
cat results/btc-updown-15m-2024-01-05.txt

# Глобальная статистика
cat results/global_summary.json
```

## Архитектура

### Модули

- **`main.rs`** - инициализация, аутентификация, CLI
- **`engine.rs`** - ядро стратегии (`RealEngine`)
- **`scanner.rs`** - поиск торговых возможностей (`AutoScanner`)
- **`websocket.rs`** - стрим обновлений ордербука (`DataStream`)
- **`websocket_user.rs`** - стрим событий пользователя (`UserStream`)
- **`models.rs`** - `Portfolio`, `MarketPrices`, `TargetMarket`, etc.
- **`report.rs`** - `Reporter` для логирования

### Многопоточность

- **Shared State**: `Arc<Mutex<Portfolio>>` для безопасного доступа
- **Concurrent Streams**: `tokio::select!` для параллельной обработки market/user events
- **Background Tasks**: `tokio::spawn` для размещения и отмены ордеров

## FAQ

**Q: Почему требуется nightly Rust?**
A: Проект использует Edition 2024, которое доступно только в nightly toolchain.

**Q: Бот не находит рынки**
A: Проверьте, что есть активные "btc-updown-15m" events в ближайшие 15 минут на Polymarket.

**Q: WebSocket disconnected**
A: Проверьте интернет-соединение и правильность URL в `.env`.

**Q: Как остановить бота?**
A: Нажмите `Ctrl+C` в терминале. Бот автоматически финализирует текущие позиции.
